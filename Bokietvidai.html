Thuật Toán Tạo Seed & Biến Số Ngoại Cảnh: - Cấu trúc Seed dự phóng = `phien_tiếp_theo` + `Timestamp_ms` + `Nhiệt_độ_hiện_tại(°C)`. - Băm chuỗi Seed này qua MD5 để tạo ra biến số ngẫu nhiên giả định cho phiên mới. - Cho phép lấy nhiệt độ từ Open-Meteo API (mặc định 30°C nếu không có vị trí). 2. Mô Hình Dự Đoán Tương Quan Tải Trọng (Weighted Hybrid Model): Không dùng thuần túy MD5 để đoán, hãy kết hợp 3 chỉ số theo trọng số: - Trọng số 1 (40%): Thuật toán Soi cầu Lịch sử từ API (Phân tích chuỗi 20 phiên gần nhất: Cầu bệt, Cầu 1-1, Cầu 2-2). - Trọng số 2 (35%): Phân tích Biến động Tiền cược Realtime từ API (Tỷ lệ chênh lệch `tien_cuoc.tai` vs `tien_cuoc.xiu` và số lượng `nguoi_cuoc`). - Trọng số 3 (25%): Giá trị Hex trích xuất từ Seed Ngoại cảnh (Timestamp + Nhiệt độ). - Tổng hợp 3 trọng số để tính % xác suất ra "XOÀI" hoặc "TÁO". 3. Tự Điều Chỉnh Học Máy Nông (Adaptive Machine Learning Bias): - Khi API cập nhật phiên mới, tự động so sánh Kết quả Dự đoán với Kết quả Thực tế từ API. - Nếu DỰ ĐOÁN SAI: Hệ thống tự động giảm trọng số của phương pháp sai và tăng trọng số của phương pháp đúng cho phiên kế tiếp (Adaptive Bias Adjustment). 4.
